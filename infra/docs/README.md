# Architecture Documentation

This directory contains high‑level diagrams and supplementary documentation for the BidBrief platform.  Use [Mermaid](https://mermaid-js.github.io/) or [PlantUML](https://plantuml.com/) to describe the architecture, data flows and processes.

## Suggested Diagrams

* **Service Overview** – Show how the web app, API, worker, database, Redis and MinIO interact.
* **Processing Pipeline** – Detail the stages of pack ingestion, extraction, answer planning, drafting and export.
* **Database Schema** – ER diagram outlining the core tables, relationships and indexes.

Diagrams can be referenced from the main `README.md` to aid comprehension.
